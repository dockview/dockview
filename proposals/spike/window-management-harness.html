Window Management spike harness

Setup

A1 — no-await ordering

Kicks off getScreenDetails() (may prompt) and calls window.open in the same synchronous task. PASS = popup opens even while the permission prompt is showing.

A2 — fullscreen popup feature

Opens popup,fullscreen at the chosen screen's origin. PASS = window appears fullscreen on that screen with no further call.

A3 — cross-screen clamping

Opens a plain popup at the chosen screen's coordinates, then reads back screenX/screenY after load. Run once before granting the permission (expect clamping to the current screen) and once after (expect the target coordinates).

Log

A4 — Electron notes (separate shell)

In a minimal Electron app loading this page: (1) with no setPermissionRequestHandler, getScreenDetails() should resolve without a prompt (default grant); (2) a window opened via window.open from this page should allow synchronous same-origin DOM access (child.document.body.append(...)) — the invariant dockview's popouts rely on.
