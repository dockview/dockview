    dockview-core

    Internal core layout engine. Not a supported install target.

    dockview-core is an internal package. It is published only because the public packages depend on it at install time. Install one of these instead:

    • dockview - JavaScript / TypeScript
    • dockview-react - React
    • dockview-vue - Vue 3
    • dockview-angular - Angular

    dockview re-exports this package in full, so everything documented on the website is available from dockview or a framework binding.

    Documentation: https://dockview.dev
