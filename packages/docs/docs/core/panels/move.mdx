A panel can be relocated to a different group and position without being destroyed and re-created. Use `moveTo` on the panel API to reposition it relative to another group and index.

## Methods

<DocRef declaration="DockviewPanelApi" methods={['moveTo']} />

## Move a panel

You can move a panel through the [Panel API](/docs/api/dockview/panelApi) and you can find out how to move a group [here](/docs/core/groups/move).

```ts
panel.api.moveTo({ group, position, index });
```

## Tab groups

An `index` never splits a [tab group](/docs/core/panels/tabGroups). If it falls between two tabs of a tab group, the panel moves to the nearer edge of that tab group instead.

To say where in the tab strip a panel goes, pass `at`, a `TabStripTarget`:

- `{ index }` places it at that index, outside any tab group. A plain `index` is shorthand for it.
- `{ tabGroup, index }` places it in a tab group (the tab group or its id), at `index` among the tab group's tabs, or at the end when `index` is left out.

```ts
// join a tab group as its second tab
panel.api.moveTo({ group, at: { tabGroup, index: 1 } });

// leave any tab group
panel.api.moveTo({ group, at: { index: 0 } });
```

`index` and `at` can't be combined. A tab group must belong to `group`, and `position` must be `'center'` (or omitted). Otherwise `moveTo` throws without changing the layout. `addPanel` accepts the same `index` and `at` options in its `position`.

`onDidMovePanel` reports where the panel landed as `event.at`, and `onWillDrop` and `onDidDrop` report where a drop on the tab bar lands the same way.

## Move a group

An equivalent method for moving groups is available on the group `api`.

```ts
const group = panel.api.group;
group.api.moveTo({ group, position });
```
