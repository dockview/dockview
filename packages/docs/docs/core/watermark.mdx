When there is nothing else to display.

When Dockview is empty or a group has no panels (an empty group) you can render some fallback
content which is referred to as a `watermark`. Both are controlled through the same provided component.

<CodeRunner id="dockview/watermark" />

## Empty state behaviour

By default, when Dockview has no panels it renders a watermark. You can change this with `noPanelsOverlay`:

- `'watermark'` (default): renders your `watermarkComponent` when empty
- `'emptyGroup'`: keeps an empty group visible instead

<FrameworkSpecific framework="React">
    ```tsx
    <DockviewReact
        noPanelsOverlay="emptyGroup"
        onReady={onReady}
        components={components}
    />
    ```
</FrameworkSpecific>

<FrameworkSpecific framework='Vue'>
```html
<dockview-vue
    noPanelsOverlay="emptyGroup"
    :components="components"
    @ready="onReady">
</dockview-vue>
```
</FrameworkSpecific>

<FrameworkSpecific framework='Angular'>
```html
<dv-dockview
    noPanelsOverlay="emptyGroup"
    [components]="components"
    (ready)="onReady($event)">
</dv-dockview>
```
</FrameworkSpecific>

<FrameworkSpecific framework='JavaScript'>
```ts
const api = createDockview(element, {
    noPanelsOverlay: 'emptyGroup',
    createComponent: (options) => new MyPanel(),
});
```
</FrameworkSpecific>

## Keeping empty groups

By default a group is removed as soon as its last panel is closed or dragged out. Set `closeEmptyGroups` to `false` to keep every emptied group in place, rendering its watermark, until the group itself is closed via `group.api.close()` or `api.removeGroup()`. This is useful when the grid is a fixed layout that panels come and go from.

<FrameworkSpecific framework="React">
    ```tsx
    <DockviewReact
        closeEmptyGroups={false}
        onReady={onReady}
        components={components}
    />
    ```
</FrameworkSpecific>

<FrameworkSpecific framework='Vue'>
```html
<dockview-vue
    :closeEmptyGroups="false"
    :components="components"
    @ready="onReady">
</dockview-vue>
```
</FrameworkSpecific>

<FrameworkSpecific framework='Angular'>
```html
<dv-dockview
    [closeEmptyGroups]="false"
    [components]="components"
    (ready)="onReady($event)">
</dv-dockview>
```
</FrameworkSpecific>

<FrameworkSpecific framework='JavaScript'>
```ts
const api = createDockview(element, {
    closeEmptyGroups: false,
    createComponent: (options) => new MyPanel(),
});
```
</FrameworkSpecific>

`api.removePanel(panel, { removeEmptyGroup })` overrides the option for a single call. `api.closeAllGroups()` and `api.clear()` remove the groups as well as their panels, except that `closeAllGroups()` keeps the last group when `noPanelsOverlay` is `'emptyGroup'`.
