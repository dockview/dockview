## Auto-resizing

By default, Dockview uses a `ResizeObserver` to automatically detect when the container element changes size and updates the layout accordingly. This requires no configuration.

If you need to manage sizing yourself, for example when embedding Dockview inside a container that doesn't produce `ResizeObserver` notifications, you can disable auto-resizing and call `api.layout()` manually.

```tsx
// Disable the internal ResizeObserver
disableAutoResizing={true}

// Then manually drive layout updates:
api.layout(width, height);
```

<FrameworkSpecific framework='JavaScript'>
```ts
const api = createDockview(element, {
    theme: themeAbyss,
    disableAutoResizing: true,
    createComponent: (options) => new MyPanel(),
});

// Call whenever the container size changes
api.layout(element.clientWidth, element.clientHeight);

````
</FrameworkSpecific>

<FrameworkSpecific framework='React'>
```tsx
const apiRef = React.useRef<DockviewApi>();

const onReady = (event: DockviewReadyEvent) => {
    apiRef.current = event.api;
};

// Trigger a resize when needed:
apiRef.current?.layout(width, height);

return (
    <DockviewReact
        disableAutoResizing={true}
        onReady={onReady}
        components={components}
    />
);
````

</FrameworkSpecific>

<FrameworkSpecific framework='Vue'>
```ts
methods: {
    onReady(event: DockviewReadyEvent) {
        this.api = event.api;
    },
    resize(width: number, height: number) {
        this.api?.layout(width, height);
    },
},
template: `<dockview-vue :disableAutoResizing="true" @ready="onReady" />`,
```
</FrameworkSpecific>

<FrameworkSpecific framework='Angular'>
```ts
export class AppComponent {
    private api: DockviewApi;

    onReady(event: DockviewReadyEvent) {
        this.api = event.api;
    }

    resize(width: number, height: number) {
        this.api?.layout(width, height);
    }

}

// In template:
// <dv-dockview [disableAutoResizing]="true" (ready)="onReady($event)" />

````
</FrameworkSpecific>

:::info
You can read the current dimensions at any time via `api.width` and `api.height`.
:::

## Proportional layout

When the container is resized, Dockview shares the extra (or missing) space out
between the groups of each row and column proportionally, so every group keeps
its share of the layout.

Set `proportionalLayout={false}` to hand the whole delta to the last group in
each row/column instead. Every splitter but the last one then stays exactly
where the user left it, which is how VS Code behaves. If the last group reaches
its minimum or maximum size, the remainder moves on to the group before it.
This applies to the nested layouts inside floating and popout windows too.

```tsx
proportionalLayout={false}
```

<FrameworkSpecific framework='JavaScript'>
```ts
const api = createDockview(element, {
    theme: themeAbyss,
    proportionalLayout: false,
    createComponent: (options) => new MyPanel(),
});
```
</FrameworkSpecific>

<FrameworkSpecific framework='React'>
```tsx
<DockviewReact
    proportionalLayout={false}
    onReady={onReady}
    components={components}
/>
```
</FrameworkSpecific>

<FrameworkSpecific framework='Vue'>
```html
<dockview-vue :proportionalLayout="false" @ready="onReady" />
```
</FrameworkSpecific>

<FrameworkSpecific framework='Angular'>
```html
<dv-dockview [proportionalLayout]="false" (ready)="onReady($event)" />
```
</FrameworkSpecific>

The option can also be changed after initialization with
`api.updateOptions({ proportionalLayout })`. Re-enabling it adopts the group
sizes in place at that moment as the proportions to preserve, rather than the
proportions from before it was disabled. Passing `undefined` restores the
default.

## Corner resizing

Where a row splitter meets a column splitter, hovering the junction shows a
move cursor and dragging it resizes along both axes at once. This is on by
default. Set `disableCornerResize` to drag each splitter on its own.

```tsx
disableCornerResize={true}
```

```ts
const api = createDockview(element, {
    theme: themeAbyss,

});
```
</FrameworkSpecific>

</FrameworkSpecific>

The option can also be changed after initialization with
`api.updateOptions({ disableCornerResize })`. Locking the layout disables
corner resizing along with the rest of the splitters.

## Hiding borders

By default, Dockview renders thin borders between groups in the grid. The `hideBorders` option removes them. See [Hiding borders](/docs/core/theming#hiding-borders) on the theming page for the full example.

## Updating options at runtime

`api.updateOptions()` lets you change any option after the component has initialized. Only the provided keys are updated; others remain unchanged.

```ts
api.updateOptions({
    hideBorders: true,
    locked: false,
    theme: themeLight,
});
```
