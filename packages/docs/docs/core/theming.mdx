Dockview components accept a `theme` property which is highly customisable. Theming is largely controlled through CSS variables, however some properties can only be adjusted by editing the `theme` object directly.

Make sure you have imported `dockview.css` as described in [Installation](/docs/overview/installation).

## Hiding borders

The `hideBorders` option removes the borders rendered between groups in the grid. This is a layout option rather than a CSS variable, useful when your theme already provides sufficient visual separation between groups.

<FrameworkSpecific framework="React">
    ```tsx
    <DockviewReact
        hideBorders={true}
        theme={themeAbyss}
        onReady={onReady}
        components={components}
    />
    ```
</FrameworkSpecific>

<FrameworkSpecific framework='Vue'>
```vue
<script setup lang="ts">
import { themeAbyss } from 'dockview-vue';

const theme = themeAbyss;

</script>

<template>
    <dockview-vue
        :hideBorders="true"
        :theme="theme"
        :components="components"
        @ready="onReady"
    />
</template>
```
</FrameworkSpecific>

<FrameworkSpecific framework='Angular'>

import { themeAbyss } from 'dockview';

@Component({

## Provided themes

`dockview` comes with a number of built-in themes. Each theme is represented as an object that can be imported.

For dock components pass the theme object to the `theme` property. For other components such as split, pane, and grid views, set the theme's associated CSS class on the `className` property.

```tsx
import { themeAbyss } from 'dockview-react';

// For dock components
theme = { themeAbyss };

// For other components
const { className } = themeAbyss;
```

## Build your own theme

A theme is a CSS class that sets `--dv-*` custom properties, plus a `DockviewTheme` object that names it. Every built-in theme is built this way: its class declares custom properties and nothing else, and all rendering (rounded cards, folder tabs, pills, dividers, floating frames) is done by dockview's own stylesheet from those properties. So anything a built-in theme does, your theme can do with variables alone.

The quickest start is `themeBase`. It derives every colour, radius and padding from five base tokens, so your class only has to set those, and you override individual properties to customise further:

```css
.my-theme {
    color-scheme: light;
    --dv-background-color: #ffffff;
    --dv-foreground-color: #1f2328;
    --dv-accent-color: #0a7d5a;
    --dv-spacing: 4px; /* tab padding */
    --dv-border-radius: 8px; /* groups, floating groups, tabs, sashes... */

    /* optional: override any derived property */
    --dv-tabs-and-actions-container-background-color: #f6f8fa;
}
```

| Base token              | Derived from it (unless set)                                                                    |
| ----------------------- | ----------------------------------------------------------------------------------------------- |
| `--dv-background-color` | content, selected tab and floating frame; the tab strip, unselected tabs and hover as steps away from it (darker on a light `color-scheme`, lighter on a dark one) |
| `--dv-foreground-color` | tab text (at 100/75/65/50%), separators and tab dividers (18%), icon hover (15%), scrollbars     |
| `--dv-accent-color`     | focus ring, drop line and fill, active sash, edge indicator                                     |
| `--dv-spacing`          | tab padding                                                                                     |
| `--dv-border-radius`    | group, floating, peek and drop-target radii; tab and dropdown (⅔), sash (⅓), drop indicator (¼) |

Add your class next to the base theme's. Layout styles are classes too: `dockview-spaced` lays groups out as rounded cards with `--dv-spacing-padding` between them, and `dockview-tabs-connected` gives folder tabs. Load your stylesheet after dockview's so your values win.

```ts
import { themeBase } from 'dockview';

const myTheme: DockviewTheme = {
    ...themeBase,
    name: 'mine',
    colorScheme: 'light',
    className: `dockview-spaced ${themeBase.className} my-theme`,
};
```

To recolour an existing theme while keeping its layout, add `dockview-base-colors` next to it: its colours then derive from the base tokens, and its spacing, radii and tab shapes stay as they are.

```ts
const myTheme: DockviewTheme = {
    ...themeSlateDark,
    className: `${themeSlateDark.className} dockview-base-colors my-theme`,
};
```

The [theme builder](/theme-builder) edits these tokens with a live preview, starts from any built-in theme, and exports the class and theme object.

A fully hand-specified theme, like the built-in ones, sets the derived properties directly:

```css
.my-theme {
    --dv-group-view-background-color: #ededee;
    --dv-tabs-and-actions-container-background-color: #ededee;
    --dv-activegroup-visiblepanel-tab-background-color: #ffffff;
    --dv-activegroup-visiblepanel-tab-color: #2563eb;
    /* ... */

    /* connected "folder" tabs */
    --dv-tab-border-radius: 10px;
    --dv-tab-content-side-border-radius: 0;
    --dv-tab-shoulder-size: 10px;
    --dv-tab-gap: 12px;
    --dv-tabs-container-padding: 0 16px;

    /* rounded content sheets on a canvas, 8px apart */
    --dv-border-radius: 6px;
    --dv-content-border-radius: 6px;
    --dv-content-background-color: #ffffff;
    --dv-group-gap: 8px;
}
```

```ts
const myTheme: DockviewTheme = { name: 'mine', className: 'my-theme' };
```

The built-in themes are also available as SCSS mixins (for example `dockview-connected-tabs-mixin` and `dockview-design-space-mixin`) and utility classes (`.dockview-tabs-connected`, `.dockview-spaced`) that set a coherent group of these properties at once.

## Theme settings

A theme's layout and drag-and-drop settings can be given on the `DockviewTheme` object or as CSS custom properties on the theme class. A value on the object wins; otherwise the CSS property is used, then the default. The built-in themes declare them in CSS, so a stylesheet can override any of them.

| Theme object             | CSS custom property              | Default                          |
| ------------------------ | -------------------------------- | -------------------------------- |
| `gap`                    | `--dv-group-gap`                 | `0`                              |
| `edgeGroupCollapsedSize` | `--dv-edge-group-collapsed-size` | the tab strip height, else `35`  |
| `dndOverlayMounting`     | `--dv-dnd-overlay-mounting`      | `'relative'`                     |
| `dndPanelOverlay`        | `--dv-dnd-panel-overlay`         | `'content'`                      |
| `dndTabIndicator`        | `--dv-dnd-tab-indicator`         | `'fill'`                         |
| `tabGroupIndicator`      | `--dv-tab-group-indicator`       | `'wrap'`                         |
| `tabAnimation`           | `--dv-tab-animation`             | `'default'`                      |

The CSS values are read when the theme is applied (on creation and on `updateOptions`). After changing them at runtime, call `api.refreshTheme()`. `api.themeSettings` returns the resolved values, and `resolveDockviewThemeSettings(theme)` resolves a theme's settings without a dockview instance.

`dndOverlayBorder` sets `--dv-drag-over-border`, so it too can be set in CSS directly.

## Theme properties

The individual settings are described below.

### `tabAnimation`

Controls how tabs animate when they are reordered or moved across groups.

- `'default'` (default): no animation, tabs snap to their new position.
- `'smooth'`: animated FLIP transition between positions, including for vertical tab strips and cross-group moves.

```ts
import { themeAbyss } from 'dockview-react';

const theme = { ...themeAbyss, tabAnimation: 'smooth' as const };
```

### `tabGroupIndicator`

Controls how the indicator under a tab group's tabs is rendered.

- `'wrap'` (default): a continuous coloured bar wraps the group's tabs.
- `'none'`: no indicator is drawn.

### `dndOverlayBorder`

A CSS `border` value for the drop preview (the highlight that appears when dragging a panel over a group), for example `'2px solid var(--dv-active-sash-color)'`. It sets `--dv-drag-over-border`, which a theme can also set in CSS.

### `dndTabIndicator`

Controls how the drop position indicator within a tab strip is drawn while dragging a tab.

- `'line'`: a thin coloured line marks the insertion point.
- `'fill'`: the target slot is filled with the active accent colour.

### `edgeGroupCollapsedSize`

The pixel size of an [edge group](/docs/core/groups/edgeGroups) when it is collapsed. It defaults to the theme's tab strip height (`--dv-tabs-and-actions-container-height`), so a collapsed rail matches the strip; set it (or `--dv-edge-group-collapsed-size`) when you need a different rail size.

### `colorScheme`

Hint passed to the browser via the `color-scheme` CSS property, either `'light'` or `'dark'`. Native form controls and scrollbars adapt accordingly.

## Extending theme

You can extend existing themes or create new ones.

As an example, to give the **dockview-theme-abyss** theme a 2px rule under the tab strip in the visible tab's colour, and pill-shaped tabs:

```css
.dockview-theme-abyss {
    --dv-tabs-and-actions-container-border-bottom-width: 2px;
    --dv-tab-border-radius: 6px;
    --dv-tab-margin: 4px 2px;
}
```

To opt an existing theme into connected folder tabs, add the `dockview-tabs-connected` class alongside it (for example through the `className` option), or set the variables it sets yourself.
